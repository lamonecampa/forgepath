BATASAN TEKNIS

Compiler nyata, tetapi targetnya WASI.

  • Program dikompilasi dengan Clang ke WASI/WebAssembly dan dijalankan melalui runtime WASI di browser, bukan sebagai executable Windows/Linux native.
  • C memakai standar GNU C17/C23; C++ memakai GNU C++11/14/17/20/23. Perilaku OS, networking, thread, dan filesystem tidak identik dengan desktop.
  • Toolchain penuh sekitar 29 MB terkompresi dan dapat memakai ratusan MB memori saat aktif. Perangkat dengan RAM rendah bisa mengalami keterlambatan.
  • Stop akan menghentikan Web Worker yang sedang menjalankan kompilasi atau program. Hindari program dengan loop tak terbatas.
  • Jangan menganggap keberhasilan di WASI sebagai bukti bahwa program akan berjalan identik pada compiler dan sistem operasi lain.
