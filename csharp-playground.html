BATASAN TEKNIS

Roslyn sungguhan, bukan simulasi sintaks.

  • Compiler Roslyn dan runtime .NET berjalan di browser melalui WebAssembly; kode tidak dikirim ke server ForgePath.
  • Kompatibilitas API, assembly, threading, filesystem, dan akses OS dibatasi oleh runtime browser. Ini bukan pengganti Visual Studio atau SDK .NET desktop.
  • Eksekusi memakai Web Worker. Fitur ini memerlukan HTTPS atau localhost; GitHub Pages menyediakan HTTPS.
  • Proses pertama dapat berat pada RAM dan jaringan. Tutup tab jika browser kehabisan memori.
  • WasmSharp berlisensi Apache-2.0. Periksa dokumentasi proyek untuk batas dukungan dan perubahan versi.
