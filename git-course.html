01 / MODULE

Git untuk Pemula

Git adalah version control terdistribusi; GitHub adalah layanan hosting repository dan kolaborasi.

git --version git config --global user.name "Nama Anda" git config --global user.email "email@example.com"

Catatan praktik: Jangan gunakan reset --hard atau force push pada branch bersama tanpa memahami dampaknya. Jangan pernah commit token, password, atau file rahasia.

Latihan: Buat program kecil yang menerapkan konsep git untuk pemula. Jalankan, uji minimal dua kondisi, lalu catat hasilnya.
