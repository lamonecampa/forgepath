01 / DOCUMENT

Struktur dasar HTML

HTML (HyperText Markup Language) mendeskripsikan struktur dan makna konten, bukan bahasa pemrograman. Browser membaca markup lalu membangun DOM untuk dirender. Dokumen modern menggunakan HTML Living Standard.

<!doctype html> <html lang="id"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Halaman Pertama</title> </head> <body> <h1>Halo, dunia!</h1> <p>Ini halaman HTML pertama saya.</p> </body> </html>

Tiga bagian penting

  • <!doctype html> mengaktifkan mode standar browser.
  • <head> berisi metadata, judul, stylesheet, dan informasi dokumen.
  • <body> berisi konten yang ditampilkan di halaman.

Latihan: Buat index.html, ubah judul tab, bahasa dokumen, dan teks heading. Buka di browser.

02 / SYNTAX

Tag, elemen, dan atribut

Tag adalah penanda markup, elemen adalah unit lengkap yang dibentuk tag dan kontennya, sedangkan atribut memberi informasi atau konfigurasi tambahan pada elemen.

<a href="https://example.com" target="_blank" rel="noopener"> Buka Example </a> <img src="foto.jpg" alt="Pemandangan pegunungan" width="640">
  • Gunakan huruf kecil untuk nama tag dan atribut.
  • Susun elemen bersarang dengan benar, elemen terakhir dibuka ditutup lebih dulu.
  • Berikan tanda kutip pada nilai atribut.
  • Elemen void seperti img, br, input tidak memiliki tag penutup.

Jangan menghafal semua tag. Pahami pola, lalu gunakan referensi saat diperlukan.

03 / TEXT

Membuat paragraf

Gunakan <p> untuk satu unit paragraf. Browser mengatur jarak paragraf secara default. Jangan memakai banyak spasi atau baris kosong untuk mengatur layout; gunakan CSS.

<p>HTML menyusun struktur halaman web.</p> <p>CSS mengatur presentasi visual halaman.</p> <p>JavaScript menambahkan perilaku interaktif.</p>

<br> digunakan untuk pemisah baris yang memang bermakna, misalnya alamat atau puisi. <hr> menandai perubahan tema atau pemisah tematik, bukan sekadar garis dekoratif.

Latihan: Tulis tiga paragraf tentang profil, minat, dan tujuan belajar. Coba hapus paragraf dan amati perubahan struktur.

Referensi Petani Kode: Paragraf ↗

04 / HIERARCHY

Heading dan hierarki konten

Heading h1 sampai h6 membentuk hierarki judul. Pilih berdasarkan struktur dokumen, bukan ukuran visual. Ukuran, warna, dan jarak heading seharusnya diatur dengan CSS.

<h1>Panduan Berkebun</h1> <h2>Persiapan</h2> <h3>Memilih Media Tanam</h3> <h3>Menyiapkan Pot</h3> <h2>Perawatan</h2>

Hindari melompat tingkat heading hanya demi tampilan. Gunakan satu judul utama yang jelas dan subjudul yang menggambarkan bagian.

Referensi Petani Kode: Heading ↗

05 / MAINTAINABILITY

Komentar HTML

Komentar membantu memberi catatan pada kode dan tidak ditampilkan sebagai konten halaman. Jangan menyimpan password, token, data pribadi, atau rahasia di komentar karena source HTML dapat dilihat pengguna.

<!-- Navigasi utama website --> <nav aria-label="Navigasi utama"> <a href="index.html">Beranda</a> </nav>

Latihan: Tambahkan komentar untuk menandai header, konten utama, dan footer. Periksa View Source pada browser.

Referensi Petani Kode: Komentar ↗

06 / EMPHASIS

Text formatting

Gunakan elemen yang menyampaikan makna, bukan sekadar tampilan. strong menunjukkan kepentingan kuat, em memberi penekanan, mark menandai bagian relevan, dan del/ins menandai perubahan.

<p><strong>Penting:</strong> simpan pekerjaan secara berkala.</p> <p>Saya <em>sangat</em> tertarik belajar web.</p> <p>Harga lama <del>Rp100.000</del> menjadi <ins>Rp85.000</ins>.</p> <p>Kata kunci: <mark>aksesibilitas</mark>.</p>

b dan i dapat digunakan untuk kebutuhan presentasi atau istilah tertentu, tetapi jangan menggantikan semantik strong dan em jika memang ada penekanan makna.

Referensi Petani Kode: Text Formatting ↗

07 / NAVIGATION

Membuat link

Elemen anchor a membuat tautan. Atribut href menentukan tujuan: URL, path relatif, email, telepon, atau fragmen dalam halaman.

<a href="tentang.html">Tentang kami</a> <a href="#kontak">Ke bagian kontak</a> <a href="mailto:halo@example.com">Kirim email</a> <a href="https://example.com" target="_blank" rel="noopener"> Situs eksternal </a>

Gunakan teks tautan yang menjelaskan tujuan. Untuk tab baru, sertakan rel="noopener". Hindari teks generik seperti “klik di sini” tanpa konteks.

Referensi Petani Kode: Link ↗

08 / IMAGES

Menampilkan gambar

Elemen img memuat gambar melalui atribut src. Atribut alt memberikan alternatif teks untuk pembaca layar atau saat gambar gagal dimuat. Untuk gambar dekoratif, gunakan alt kosong.

<img src="images/taman.jpg" alt="Taman kecil dengan tanaman dalam pot" width="800" height="500" loading="lazy">
  • Optimalkan ukuran file dan gunakan format modern seperti WebP/AVIF bila sesuai.
  • Isi dimensi gambar untuk mengurangi layout shift.
  • Gunakan loading="lazy" untuk gambar di luar layar awal, bukan otomatis untuk gambar hero utama.
  • Pastikan memiliki hak penggunaan gambar.

Referensi Petani Kode: Image ↗

09 / LISTS

Membuat list

Gunakan unordered list untuk item yang tidak berurutan, ordered list untuk langkah atau peringkat, dan description list untuk istilah beserta penjelasannya.

<ul> <li>HTML</li> <li>CSS</li> </ul> <ol> <li>Buat file HTML</li> <li>Tulis struktur</li> <li>Buka di browser</li> </ol> <dl> <dt>HTML</dt> <dd>Bahasa markup untuk struktur web.</dd> </dl>

Latihan: Buat daftar keterampilan dan daftar langkah membuat halaman profil. Gunakan nested list hanya jika relasi bertingkat memang diperlukan.

Referensi Petani Kode: List ↗

10 / DATA

Membuat tabel

Tabel digunakan untuk data tabular, bukan untuk membuat layout halaman. Gunakan caption, thead, tbody, th, dan atribut scope agar relasi header dan sel lebih jelas.

<table> <caption>Jadwal Praktikum</caption> <thead> <tr><th scope="col">Hari</th><th scope="col">Mata Kuliah</th></tr> </thead> <tbody> <tr><td>Senin</td><td>Pemrograman Web</td></tr> <tr><td>Rabu</td><td>Basis Data</td></tr> </tbody> </table>

Untuk tabel kompleks, pelajari rowspan, colspan, dan header berkelompok. Pastikan tabel tetap dapat dipahami pada layar kecil.

Referensi Petani Kode: Tabel ↗

11 / INPUT

Membuat form

Form mengumpulkan input pengguna. Hubungkan setiap kontrol dengan label, pilih tipe input yang sesuai, dan tentukan atribut name agar nilainya dapat dikirim.

<form action="/kontak" method="post"> <label for="nama">Nama</label> <input id="nama" name="nama" type="text" required> <label for="email">Email</label> <input id="email" name="email" type="email" required> <label for="pesan">Pesan</label> <textarea id="pesan" name="pesan"></textarea> <button type="submit">Kirim</button> </form>

Validasi HTML di sisi browser membantu pengalaman pengguna, tetapi bukan pengganti validasi server. Data dari pengguna harus dianggap tidak tepercaya dan divalidasi kembali di backend.

Referensi Petani Kode: Form ↗

12 / MEANING

HTML semantik

Elemen semantik menjelaskan peran konten. Struktur yang jelas membantu pemeliharaan, navigasi pembaca layar, dan pemahaman mesin pencari. Semantik bukan tombol ajaib untuk menaikkan ranking SEO.

<header>...</header> <nav aria-label="Utama">...</nav> <main> <article> <h1>Judul artikel</h1> <section>...</section> </article> <aside>Konten terkait</aside> </main> <footer>...</footer>

Gunakan main untuk konten utama, nav untuk navigasi, article untuk konten mandiri, section untuk kelompok tematik, dan aside untuk konten terkait. Jangan mengganti semua div secara membabi buta.

Referensi Petani Kode: Semantik ↗

13 / VIDEO

Menambahkan video

Elemen video mendukung pemutaran media di browser. Sediakan kontrol, fallback, dan subtitle bila tersedia. Jangan memaksa autoplay dengan suara.

<video controls width="640" poster="thumbnail.jpg"> <source src="video.mp4" type="video/mp4"> Browser Anda tidak mendukung video HTML. </video>

Untuk aksesibilitas, sediakan caption/subtitle melalui track dengan file WebVTT. Perhatikan ukuran file, format codec, hak cipta, dan bandwidth.

Referensi Petani Kode: Video ↗

14 / AUDIO

Menambahkan audio

Gunakan audio untuk menyematkan suara. Browser dapat memilih source yang didukung. Kontrol native memberi pengguna kendali pemutaran.

<audio controls preload="metadata"> <source src="narasi.mp3" type="audio/mpeg"> <source src="narasi.ogg" type="audio/ogg"> Browser Anda tidak mendukung audio. </audio>

Hindari autoplay yang mengganggu. Sediakan transkrip untuk konten audio yang menyampaikan informasi penting dan pastikan file media memiliki izin penggunaan.

Referensi Petani Kode: Audio ↗

15 / BUILD

Proyek: website pribadi

Gabungkan materi menjadi website profil sederhana. Targetnya bukan desain rumit, tetapi struktur konsisten, navigasi berfungsi, konten bermakna, dan tampilan responsif.

Spesifikasi minimum

  1. Header berisi nama atau identitas proyek.
  2. Navigasi ke bagian Profil, Keahlian, Proyek, dan Kontak.
  3. Konten utama menggunakan heading dan paragraf yang terstruktur.
  4. Daftar keahlian, tabel ringkas bila benar-benar cocok untuk data tabular, dan gambar dengan alt.
  5. Form kontak dengan label yang benar. Tanpa backend, jelaskan bahwa form hanya demonstrasi.
  6. Footer berisi informasi hak cipta atau tautan relevan.
project/ ├── index.html ├── assets/ │ ├── style.css │ └── images/ └── README.md

Uji hasil: semua link bekerja, tidak ada gambar rusak, heading berurutan, halaman dapat digunakan di ponsel, dan HTML diperiksa dengan Nu HTML Checker ↗.

16 / DEPLOY

Publikasikan website dengan Netlify

Website HTML/CSS/JS statis dapat di-host tanpa server aplikasi. Netlify mendukung deployment melalui Git repository atau unggah folder hasil build. Untuk proyek pertama, gunakan folder yang berisi index.html sebagai publish directory.

Alur deployment berbasis Git

  1. Pastikan proyek berjalan lokal dan file utama bernama index.html.
  2. Push folder proyek ke repository GitHub.
  3. Masuk Netlify dan hubungkan repository.
  4. Atur build command kosong jika tidak ada proses build, dan publish directory ke root proyek (atau folder publik yang tepat).
  5. Deploy, lalu uji URL publik, navigasi, aset, dan tampilan mobile.
Jangan unggah file rahasia, konfigurasi lokal, kredensial, atau folder dependency yang tidak diperlukan. Website statis tidak menjalankan PHP. Jika proyek membutuhkan PHP/MySQL, gunakan hosting yang mendukung backend atau arsitektur layanan terpisah.
