MODULE 01 / OVERVIEW

Mengenal PHP dan perannya di web

PHP adalah bahasa pemrograman server-side yang dirancang kuat untuk pengembangan web. Kode PHP diproses di server, bukan dikirim sebagai kode mentah untuk dieksekusi browser. Hasil pemrosesan biasanya berupa HTML, JSON, atau respons lain yang diterima client.

Bayangkan sebuah halaman katalog. HTML membentuk struktur kartu produk, CSS mengatur tampilannya, JavaScript menangani interaksi di browser, sedangkan PHP mengambil data produk dan menentukan konten yang dikirim ke browser.

// halo.php <?php $nama = "ForgePath"; echo "<h1>Selamat belajar, " . htmlspecialchars($nama) . "!</h1>"; ?>

Alur request sederhana

  1. Browser mengirim HTTP request ke server.
  2. Web server meneruskan file PHP ke interpreter.
  3. PHP menjalankan logika dan dapat membaca database.
  4. Server mengirim response yang sudah diproses ke browser.

Jalankan dengan PHP CLI: php -S localhost:8000, lalu buka http://localhost:8000/halo.php. PHP bukan pengganti HTML atau JavaScript. Ketiganya mengerjakan bagian berbeda.

Gunakan versi PHP yang masih mendapat dukungan keamanan dan sesuai kebutuhan framework/hosting. Periksa jadwal dukungan versi PHP, jangan memilih versi hanya karena tutorial memakai versi tersebut.
MODULE 02 / VARIABLES

Variabel dan konstanta

Variabel memberi nama pada suatu nilai agar dapat digunakan kembali atau diperbarui. Nama variabel PHP diawali tanda dolar ($), diikuti huruf atau garis bawah, lalu dapat memuat angka. Nama bersifat case-sensitive: $nama dan $Nama adalah dua variabel berbeda.

<?php $nama = "Alya"; $umur = 20; $aktif = true; $umur = $umur + 1; const NAMA_APLIKASI = "KampusApp"; echo $nama . " berusia " . $umur; ?>

Gunakan nama yang menjelaskan maksud, misalnya $totalBelanja, bukan $x. Untuk nilai yang tidak boleh berubah selama eksekusi, gunakan konstanta. PHP juga menyediakan define(), tetapi deklarasi const sering lebih mudah dibaca untuk konstanta sederhana.

Interpolasi dan penggabungan

$nama = "Alya"; echo "Halo, $nama"; // interpolasi string double quote echo 'Halo, ' . $nama; // operator concatenation
MODULE 03 / DATA TYPES

Tipe data dasar dan konversi

PHP menentukan tipe nilai secara dinamis, tetapi tipe tetap memengaruhi operasi dan hasil. Empat tipe dasar yang sering ditemui adalah string, integer, float, dan boolean. Ada pula null, array, object, resource, dan tipe lainnya.

$judul = "Pemrograman PHP"; // string $jumlah = 12; // integer $harga = 12500.50; // float $tersedia = true; // boolean $catatan = null; // null var_dump($jumlah, $harga, $tersedia);
  • String: teks, misalnya nama dan alamat email.
  • Integer: bilangan bulat, misalnya jumlah barang.
  • Float: bilangan pecahan. Hindari float untuk perhitungan uang yang harus presisi; simpan nominal sebagai integer dalam satuan terkecil atau gunakan pendekatan decimal yang sesuai.
  • Boolean: true atau false, lazim untuk status dan hasil kondisi.

PHP dapat melakukan konversi tipe otomatis (type juggling). Konversi ini praktis, tetapi bisa menimbulkan hasil tak terduga. Validasi dan konversi input secara eksplisit, misalnya $umur = filter_input(INPUT_POST, 'umur', FILTER_VALIDATE_INT).

Jangan menyamakan string angka dengan integer tanpa memeriksa konteks. Gunakan perbandingan identik === ketika tipe dan nilai sama-sama harus cocok.
MODULE 04 / OPERATORS

Operator aritmatika, perbandingan, dan logika

Operator melakukan perhitungan atau membentuk ekspresi kondisi. Operator aritmatika meliputi +, -, *, /, %, dan **. Operator penugasan seperti += mempersingkat pembaruan nilai.

$subtotal = 150000; $diskon = 0.10; $total = $subtotal - ($subtotal * $diskon); $jumlah = 7; $sisa = $jumlah % 2; // 1

Operator perbandingan menghasilkan boolean: ===, !==, >, <, >=, dan <=. Operator logika menggabungkan kondisi: && (dan), || (atau), serta ! (negasi).

$umur = 21; $punyaKartu = true; if ($umur >= 17 && $punyaKartu) { echo "Syarat terpenuhi"; }

Biasakan memakai === dan !== untuk menghindari perbandingan longgar yang melakukan konversi tipe. Waspadai pula perbedaan prioritas operator and/or dibanding &&/||; gunakan bentuk simbolik dan tanda kurung agar maksud ekspresi jelas.

MODULE 05 / CONDITIONS

Percabangan if, elseif, dan else

Percabangan memilih instruksi berdasarkan kondisi. PHP mengevaluasi kondisi dari atas ke bawah. Blok pertama yang bernilai benar akan dijalankan, sedangkan else menjadi jalur cadangan.

$nilai = 82; if ($nilai >= 85) { $predikat = "A"; } elseif ($nilai >= 75) { $predikat = "B"; } elseif ($nilai >= 60) { $predikat = "C"; } else { $predikat = "Perlu perbaikan"; } echo $predikat;

Urutan kondisi penting. Letakkan kondisi yang lebih spesifik atau ambang tertinggi terlebih dahulu. Jika kondisi umum ditempatkan di awal, kondisi setelahnya bisa tidak pernah tercapai.

Validasi input

$stok = 0; if ($stok > 0) { echo "Produk tersedia"; } else { echo "Stok habis"; }
MODULE 06 / SWITCH

Switch untuk pilihan berbasis nilai

Gunakan switch ketika satu ekspresi dibandingkan dengan beberapa nilai tetap. Struktur ini dapat lebih mudah dibaca daripada rangkaian elseif panjang. Akhiri setiap case dengan break bila tidak ingin eksekusi berlanjut ke case berikutnya.

$menu = "laporan"; switch ($menu) { case "beranda": echo "Halaman utama"; break; case "laporan": echo "Halaman laporan"; break; case "pengaturan": echo "Halaman pengaturan"; break; default: echo "Halaman tidak ditemukan"; }

Untuk kondisi berupa rentang nilai, perbandingan kompleks, atau aturan yang tidak sekadar mencocokkan nilai, if/elseif biasanya lebih tepat. PHP modern juga memiliki match expression, yang berbeda dari switch karena menghasilkan nilai dan menggunakan perbandingan identik.

MODULE 07 / LOOPS

Perulangan for, while, dan foreach

Loop menjalankan blok instruksi berkali-kali. for cocok saat jumlah iterasi dapat ditentukan, while saat pengulangan bergantung pada kondisi, dan foreach untuk menelusuri elemen array atau iterable.

// for: sepuluh iterasi for ($i = 1; $i <= 5; $i++) { echo $i . PHP_EOL; } // while: selama syarat terpenuhi $stok = 3; while ($stok > 0) { echo "Sisa: $stok" . PHP_EOL; $stok--; } // foreach: membaca array $buah = ["Apel", "Jeruk", "Mangga"]; foreach ($buah as $item) { echo $item . PHP_EOL; }

break menghentikan loop, sedangkan continue melewati sisa instruksi pada iterasi saat ini. Pastikan kondisi loop dapat berubah; jika tidak, program berisiko masuk infinite loop.

MODULE 08 / FUNCTIONS

Fungsi, parameter, return value, dan scope

Fungsi membungkus pekerjaan tertentu agar dapat dipanggil berulang. Parameter menjadi masukan, sedangkan return mengirim hasil kembali ke pemanggil. Fungsi yang baik memiliki satu tanggung jawab yang jelas.

function hitungDiskon(float $harga, float $persen): float { return $harga * ($persen / 100); } $potongan = hitungDiskon(200000, 15); echo $potongan; // 30000

Variabel yang dibuat di dalam fungsi umumnya memiliki local scope. Variabel di luar fungsi tidak otomatis tersedia di dalamnya. Kirim data melalui parameter, bukan bergantung pada global state. Kata kunci global tersedia tetapi penggunaannya berlebihan membuat fungsi sulit diuji. Variabel static lokal mempertahankan nilainya di antara pemanggilan fungsi.

function penghitung(): int { static $jumlah = 0; $jumlah++; return $jumlah; } echo penghitung(); // 1 echo penghitung(); // 2

Kenali juga type declaration, nullable type, default parameter, named arguments, dan anonymous function setelah konsep dasar dikuasai.

MODULE 09 / ARRAYS

Array indexed, associative, dan multidimensi

Array menyimpan banyak nilai dalam satu variabel. Indexed array memakai indeks numerik, associative array memakai key bernama, dan multidimensional array menyimpan array di dalam array.

$warna = ["merah", "hijau", "biru"]; echo $warna[0]; $mahasiswa = [ "nama" => "Rani", "nim" => "24001", "prodi" => "Teknik Elektro" ]; echo $mahasiswa["nama"]; $data = [ ["nama" => "Rani", "nilai" => 88], ["nama" => "Dito", "nilai" => 91] ]; foreach ($data as $baris) { echo $baris["nama"] . ": " . $baris["nilai"]; }

Fungsi array yang sering dipakai antara lain count(), array_push(), array_pop(), array_merge(), array_filter(), array_map(), dan array_reduce(). Perhatikan apakah fungsi mengubah array asal atau menghasilkan array baru.

MODULE 10 / BUILT-IN FUNCTIONS

Fungsi bawaan PHP

PHP menyediakan fungsi untuk pekerjaan umum sehingga tidak perlu menulis semuanya dari nol. Kelompok penting: manipulasi string, angka, array, tanggal/waktu, file, dan validasi.

$teks = " Belajar PHP "; echo trim($teks); echo strlen($teks); echo strtoupper($teks); $angka = [8, 3, 9, 1]; sort($angka); echo count($angka); $tanggal = new DateTimeImmutable("now"); echo $tanggal->format("Y-m-d");

Contoh lain: str_replace(), explode(), implode(), number_format(), in_array(), array_key_exists(), file_get_contents(), dan filter_var(). Jangan mengandalkan ingatan semata; cari fungsi di manual resmi dan periksa parameter serta nilai baliknya.

MODULE 11 / FORMS & VALIDATION

Form HTML, request, dan validasi

Form mengirim data ke server melalui metode HTTP. GET lazim untuk pencarian atau filter yang dapat dibagikan melalui URL. POST lazim untuk pengiriman yang mengubah keadaan, seperti pendaftaran. POST bukan enkripsi; gunakan HTTPS untuk melindungi data saat transit.

<form method="post"> <label>Email <input type="email" name="email" required> </label> <button type="submit">Kirim</button> </form> <?php $email = filter_input(INPUT_POST, 'email', FILTER_VALIDATE_EMAIL); if ($_SERVER['REQUEST_METHOD'] === 'POST') { if ($email === false || $email === null) { $pesan = "Alamat email tidak valid"; } else { $pesan = "Data diterima"; } } ?>

Validasi dilakukan di server meskipun browser memiliki atribut required atau type=email, sebab validasi client dapat dilewati. Validasi memeriksa aturan data; escaping dilakukan saat output sesuai konteks. Untuk menampilkan input sebagai HTML, gunakan htmlspecialchars($nilai, ENT_QUOTES, 'UTF-8').

Untuk form yang mengubah data, tambahkan perlindungan CSRF menggunakan token. Batasi ukuran input dan validasi setiap field dengan aturan yang sesuai kebutuhan.

MODULE 12 / DATABASE OPERATIONS

Koneksi database dan multiple insert

PHP dapat berkomunikasi dengan MySQL menggunakan PDO atau MySQLi. Untuk materi ini gunakan PDO agar pola prepared statement konsisten dan lebih mudah dipindahkan ke beberapa jenis database.

$pdo = new PDO( 'mysql:host=localhost;dbname=sekolah;charset=utf8mb4', 'app_user', 'password', [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION] ); $stmt = $pdo->prepare( 'INSERT INTO mahasiswa (nama, email) VALUES (:nama, :email)' ); $stmt->execute([ 'nama' => 'Rani', 'email' => 'rani@example.com' ]);

Jangan menyisipkan input langsung ke dalam string SQL. Prepared statement memisahkan query dari nilai yang dikirim sehingga membantu mencegah SQL injection. Untuk banyak baris, gunakan transaksi dan prepared statement berulang, atau multi-row insert dengan placeholder yang jumlahnya sesuai input.

$pdo->beginTransaction(); try { $stmt = $pdo->prepare( 'INSERT INTO mahasiswa (nama, email) VALUES (?, ?)' ); foreach ($daftar as $mhs) { $stmt->execute([$mhs['nama'], $mhs['email']]); } $pdo->commit(); } catch (Throwable $e) { $pdo->rollBack(); throw $e; }

Transaksi menjaga konsistensi: bila salah satu operasi gagal, perubahan dalam transaksi dapat dibatalkan. Pelajari desain tabel dan SQL di kursus MySQL.

MODULE 13 / STATE & AUTH

Session, cookie, dan autentikasi

HTTP bersifat stateless: server tidak otomatis mengingat request sebelumnya. Session menyimpan state di server dan biasanya menghubungkannya dengan ID session di cookie browser. Cookie sendiri disimpan di browser dan dapat dimodifikasi pengguna, jadi jangan jadikan isinya sebagai sumber kebenaran untuk harga, saldo, atau hak akses.

session_start(); $_SESSION['user_id'] = 42; $_SESSION['role'] = 'admin'; // Setelah login berhasil: session_regenerate_id(true); // Saat logout: $_SESSION = []; session_destroy();

Untuk autentikasi, simpan hash password dengan password_hash(), verifikasi dengan password_verify(), gunakan prepared statement, regenerasi session ID setelah login, dan batasi akses setiap halaman di sisi server. Jangan pernah menyimpan password mentah atau mengirim kredensial melalui HTTP tanpa TLS.

Shopping cart dapat memakai session untuk menyimpan daftar ID produk dan kuantitas. Harga dan total harus dihitung ulang dari database server, bukan dipercaya dari cookie atau request client.

Contoh login klasik berbasis MySQLi dapat berguna untuk memahami alur, tetapi untuk proyek baru gunakan praktik modern: prepared statements, password hashing, CSRF protection, session hardening, dan pesan error yang tidak membocorkan detail internal.
MODULE 14 / DEBUGGING

Menangani error dan debugging

Pesan error adalah petunjuk, bukan musuh. Parse error biasanya menunjukkan kesalahan sintaks, warning menunjukkan masalah saat eksekusi yang tidak selalu menghentikan program, sedangkan fatal error menghentikan proses. Jenis dan level pesan dapat berbeda menurut versi PHP.

error_reporting(E_ALL); ini_set('display_errors', '1'); // hanya lingkungan development $data = ['nama' => 'Rani', 'nilai' => 90]; var_dump($data); print_r($data); // Periksa sintaks dari terminal php -l index.php

Gunakan var_dump() untuk melihat nilai beserta tipe, dan print_r() untuk struktur array/object yang lebih ringkas. Periksa stack trace, file, nomor baris, serta nilai variabel di sekitar titik gagal.

Di production, jangan menampilkan detail error kepada pengunjung. Matikan display_errors, aktifkan pencatatan ke log, lindungi file log, dan tampilkan pesan umum yang tidak membocorkan query, path server, token, atau kredensial.

MODULE 15 / OBJECT-ORIENTED PHP

OOP: class, object, dan empat pilar

Object-oriented programming mengelompokkan data (property) dan perilaku (method) ke dalam class. Class menjadi rancangan, sedangkan object adalah instance yang dibuat dari rancangan tersebut.

class Produk { public function __construct( public string $nama, private int $harga ) {} public function harga(): int { return $this->harga; } public function ringkasan(): string { return $this->nama . ' - Rp' . $this->harga(); } } $produk = new Produk('Keyboard', 250000); echo $produk->ringkasan();
  • Encapsulation: membatasi akses ke detail internal melalui visibility dan method.
  • Inheritance: class turunan mewarisi atau memperluas perilaku class dasar.
  • Polymorphism: objek berbeda dapat digunakan melalui kontrak/interface yang sama.
  • Abstraction: menampilkan kontrak penting tanpa mengekspos seluruh detail implementasi.

Materi lanjutan: interface, abstract class, trait, namespace, autoloading Composer, dependency injection, dan testing. Jangan memaksakan OOP pada program kecil yang lebih jelas ditulis secara prosedural; gunakan saat struktur dan tanggung jawab mulai berkembang.

Prasyarat Laravel: pahami fungsi, array, class/object, visibility, namespace, Composer, HTTP request, serta SQL dasar. Setelah itu lanjutkan ke kursus Laravel.
