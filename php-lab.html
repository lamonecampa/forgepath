PHP Lab.

Tempat menulis, membaca, dan memeriksa pola kode PHP. Eksperimen dengan contoh, lalu jalankan kode di server PHP lokal agar hasilnya benar-benar dieksekusi.

Code workspace

PHP · UTF-8
Pemeriksaan sintaks sederhana akan ditampilkan di sini. Ini bukan eksekusi PHP.

Bagaimana menjalankannya?

PHP harus dijalankan oleh interpreter PHP. Ikuti salah satu cara berikut.

Opsi A · PHP CLI

php latihan.php

Opsi B · Built-in server

cd folder-proyek php -S localhost:8000

Simpan contoh sebagai index.php, lalu buka http://localhost:8000.

Opsi C · XAMPP / Laragon

Simpan file dalam document root (misalnya htdocs), jalankan Apache, lalu buka alamat localhost.

Penting: tombol pemeriksaan tidak menjalankan interpreter PHP. Validasi dilakukan secara heuristik di JavaScript, sehingga bukan pengganti php -l file.php.
