Batas lingkungan: PHP berjalan pada virtual filesystem di browser. Ini cocok untuk sintaks, variabel, kondisi, loop, fungsi, array, OOP, dan output HTML sederhana. Ini bukan server produksi, tidak menyediakan MySQL server, dan tidak otomatis menjalankan proyek Laravel. File dan perubahan runtime dapat hilang ketika halaman dimuat ulang.

Jangan menjalankan kode yang tidak dipahami. Hindari loop tak berujung dan kode yang mengonsumsi memori berlebihan. Jangan masukkan password, token, atau data rahasia. Output HTML ditampilkan dalam iframe sandbox terpisah.
