Batas eksekusi: Playground ini menjalankan HTML, CSS, dan JavaScript di browser. Kode dipisahkan dalam iframe sandbox. Ini bukan server PHP, bukan Laravel runtime, dan bukan MySQL server. PHP dan Laravel memerlukan runtime/server PHP; SQL Lab yang tersedia menggunakan SQLite WASM dengan perbedaan dialek dari MySQL.

Catatan keamanan: jangan masukkan kredensial, token, atau data pribadi ke contoh kode. Preview tidak mengirim kode ke server ForgePath, tetapi kode yang kamu tulis tetap dapat memuat resource eksternal jika kamu menambahkannya sendiri.
