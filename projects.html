PROJECT-BASED LEARNING / 04 BUILDS

Bangun. Uji. Perbaiki.

Empat proyek dengan tingkat kesulitan bertahap. Setiap proyek memiliki kriteria selesai agar hasil belajarmu dapat dievaluasi secara konkret.

Project completion

0/16

Centang kriteria yang sudah kamu uji. Progress tersimpan lokal pada browser ini.

01
BEGINNER · HTML / CSS

Personal Profile Page

Buat halaman profil sederhana yang berisi informasi diri, keahlian, minat, dan kontak. Fokus pada struktur semantik dan layout responsif.

  • Gunakan heading, paragraf, daftar, tautan, dan gambar yang tepat.
  • Atur layout dengan CSS dan uji di layar ponsel.
  • Pastikan kontras, teks alternatif gambar, dan navigasi jelas.
Definition of done
02
BEGINNER · HTML / CSS / JS

Simple Calculator

Buat kalkulator untuk operasi dasar. Fokus pada event, input, validasi, dan pemisahan tampilan dari logika.

  • Operasi tambah, kurang, kali, dan bagi.
  • Validasi input dan penanganan pembagian dengan nol.
  • Uji keyboard dan tampilan pada beberapa ukuran layar.
Definition of done
03
INTERMEDIATE · PHP / MYSQL

Student Data CRUD

Aplikasi data mahasiswa sederhana dengan PHP dan MySQL. Praktikkan koneksi database, prepared statements, validasi, dan operasi CRUD.

  • Skema tabel mahasiswa dengan primary key dan constraint yang sesuai.
  • Tambah, tampilkan, ubah, hapus data menggunakan PDO prepared statements.
  • Validasi sisi server, escaping output, dan pesan kesalahan yang aman.
Definition of done
04
ADVANCED BEGINNER · LARAVEL

Student Management App

Bangun ulang aplikasi data mahasiswa menggunakan Laravel. Tujuannya memahami pola MVC, migration, Eloquent, validasi, dan Blade.

  • Buat model, migration, controller resource, dan route.
  • Gunakan request validation dan CSRF protection bawaan framework.
  • Buat halaman daftar, tambah, edit, detail, dan hapus data.
  • Tulis instruksi instalasi dan konfigurasi environment tanpa mengunggah .env.
Definition of done
