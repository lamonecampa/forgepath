01 / ENVIRONMENT · LINUX

Menyiapkan Python di Linux

Di banyak distribusi Linux, Python 3 sudah tersedia karena dipakai oleh sistem dan aplikasi. Periksa terlebih dahulu, jangan langsung mengganti atau menghapus Python bawaan OS.

# Periksa versi Python 3 python3 --version # Debian / Ubuntu: instal interpreter dan pip sudo apt update sudo apt install python3 python3-pip python3-venv # Jalankan interpreter interaktif python3 # Jalankan file python3 hello.py

Buat file hello.py dengan print("Halo, Python!"). Untuk proyek, gunakan virtual environment agar dependensi tidak bercampur dengan paket sistem:

python3 -m venv .venv source .venv/bin/activate python -m pip install --upgrade pip python hello.py deactivate

Perintah instalasi paket dapat berbeda pada Debian/Ubuntu, Fedora, Arch, dan distribusi lain. Ikuti package manager distribusi yang digunakan. Hindari sudo pip install untuk memasang paket proyek ke Python sistem.

02 / ENVIRONMENT · WINDOWS

Menyiapkan Python di Windows

Unduh Python 3 dari situs resmi. Saat instalasi, aktifkan opsi untuk menambahkan Python ke PATH jika installer menyediakannya. Setelah instalasi, buka PowerShell atau Command Prompt baru.

# Periksa launcher dan versi Python py --version python --version # Jalankan interpreter py # Jalankan file py hello.py # Buat virtual environment py -m venv .venv .venv\\Scripts\\Activate.ps1 # Perbarui pip di environment aktif python -m pip install --upgrade pip

Jika PowerShell menolak aktivasi script, jangan asal mengubah execution policy secara global. Baca pesan error dan dokumentasi Microsoft/Python, atau gunakan Command Prompt dengan .venv\\Scripts\\activate.bat. Editor seperti VS Code perlu diarahkan ke interpreter dari virtual environment proyek.

03 / LANGUAGE BASICS

Sintaks dasar Python

Python menggunakan indentasi untuk menandai blok kode. Konsistensi indentasi wajib. Nama bersifat case-sensitive, statement umumnya ditulis satu per baris, dan komentar satu baris dimulai dengan #.

# Program pertama nama = "ForgePath" if nama: print(f"Selamat belajar, {nama}!") print("Python menggunakan indentasi.") # Fungsi sederhana def sapa(): """Docstring menjelaskan tujuan fungsi.""" print("Halo!") sapa()
  • Gunakan 4 spasi untuk satu tingkat indentasi, sesuai PEP 8.
  • Nama variabel dan fungsi umumnya memakai snake_case.
  • Nama class umumnya memakai CapWords.
  • String dapat memakai kutip tunggal atau ganda.
  • Triple quotes lazim digunakan untuk docstring, bukan komentar pengganti.

Kesalahan indentasi bukan masalah kosmetik. Python menggunakannya untuk menentukan struktur program.

04 / DATA

Variabel dan tipe data

Variabel mengikat nama ke objek. Python bersifat dynamically typed: tipe tidak perlu dideklarasikan pada setiap assignment, tetapi tipe objek tetap penting dan memengaruhi operasi yang valid.

nama = "Alya" # str umur = 20 # int tinggi = 1.65 # float aktif = True # bool catatan = None # NoneType print(type(nama)) print(type(umur)) # Konversi tipe secara eksplisit umur_teks = str(umur) angka = int("25") desimal = float("3.14")

Tipe dasar yang perlu dikenali: str, int, float, bool, dan NoneType. Konversi seperti int("abc") akan gagal; tangani input tidak valid pada modul berikutnya.

05 / INPUT & OUTPUT

Mengambil input dan menampilkan output

Gunakan print() untuk menampilkan informasi dan input() untuk menerima teks dari pengguna. Nilai yang dikembalikan input() selalu berupa string, sehingga angka perlu dikonversi.

nama = input("Nama: ") umur_teks = input("Umur: ") try: umur = int(umur_teks) except ValueError: print("Umur harus berupa bilangan bulat.") else: print(f"Halo {nama}, tahun depan umurmu {umur + 1}.") # Output dengan format harga = 12500 print(f"Harga: Rp{harga:,}")

Jangan menganggap input pengguna selalu valid. Program perlu memeriksa format, rentang, dan kemungkinan kegagalan konversi. Untuk uang, integer dalam satuan terkecil atau modul decimal lebih aman daripada float biasa.

06 / EXPRESSIONS

Operator Python

Operator membentuk ekspresi. Kenali operator aritmatika, perbandingan, logika, assignment, keanggotaan, dan identitas. Perhatikan prioritas operator; gunakan tanda kurung jika ekspresi mulai sulit dibaca.

a, b = 17, 5 print(a + b) # 22 print(a // b) # 3, floor division print(a % b) # 2, modulo print(a ** 2) # 289 print(a > b) # True print(a > 10 and b < 10) print("py" in "python") data = None print(data is None) # identity check

Gunakan == untuk membandingkan kesetaraan nilai dan is untuk identitas objek, terutama pola seperti is None. Jangan memakai is sebagai pengganti == untuk angka atau string.

Referensi Petani Kode: Operator ↗

07 / CONTROL FLOW

Percabangan

Percabangan memilih blok kode berdasarkan kondisi. Python menggunakan if, elif, dan else. Kondisi dievaluasi sebagai nilai truthy atau falsy.

nilai = 82 if nilai >= 85: predikat = "A" elif nilai >= 75: predikat = "B" elif nilai >= 60: predikat = "C" else: predikat = "Perlu perbaikan" print(f"Predikat: {predikat}")

Uji batas kondisi, misalnya nilai 59, 60, 74, 75, 84, dan 85. Kesalahan umum adalah membuat rentang yang tumpang tindih atau tidak mencakup nilai batas.

Referensi Petani Kode: Percabangan ↗

08 / ITERATION

Perulangan

Gunakan for untuk mengiterasi sequence atau iterable dan while untuk mengulang selama kondisi benar. break menghentikan loop, sedangkan continue melanjutkan ke iterasi berikutnya.

for angka in range(1, 6): print(angka) nama = ["Alya", "Bima", "Citra"] for indeks, item in enumerate(nama, start=1): print(indeks, item) hitung = 3 while hitung > 0: print(hitung) hitung -= 1 print("Selesai")

Pastikan loop while memiliki kondisi berhenti yang dapat dicapai. Loop tak berujung dapat membuat program tampak macet. Latih juga penggunaan break, continue, dan loop bersarang.

Referensi Petani Kode: Perulangan ↗

09 / DATA STRUCTURES

List

List adalah sequence yang berurutan dan mutable. List cocok untuk kumpulan item yang dapat ditambah, diubah, atau dihapus. Indeks dimulai dari nol dan slicing menggunakan batas akhir eksklusif.

nilai = [78, 90, 82] nilai.append(88) nilai.insert(1, 85) nilai.remove(78) print(nilai[0]) print(nilai[-1]) print(nilai[1:3]) for item in nilai: print(item) nilai_urut = sorted(nilai) print(nilai_urut)

Bedakan sort() yang mengubah list di tempat dan sorted() yang menghasilkan list baru. Hati-hati saat menghapus item sambil mengiterasi list yang sama.

Referensi Petani Kode: List ↗

10 / DATA STRUCTURES

Tuple

Tuple adalah sequence yang immutable. Gunakan tuple untuk kumpulan nilai yang tidak perlu diubah setelah dibuat, misalnya koordinat atau pasangan konfigurasi.

koordinat = ( -7.25, 112.75 ) x, y = koordinat print(x, y) print(koordinat[0]) # Tuple satu elemen memerlukan koma satu_item = ("Python",) # Konversi sequence daftar = list(koordinat) pasangan = tuple(daftar)

Immutable berarti elemen tuple tidak dapat diganti, tetapi jika tuple berisi objek mutable, objek di dalamnya mungkin tetap dapat berubah. Jadi, jangan menyamakan immutable dengan seluruh isi selalu beku.

Referensi Petani Kode: Tuple ↗

11 / DATA STRUCTURES

Dictionary

Dictionary menyimpan pasangan key-value. Key harus hashable dan unik. Dictionary cocok untuk merepresentasikan satu entitas dengan atribut bernama.

mahasiswa = { "nama": "Dina", "nim": "24001", "aktif": True } print(mahasiswa["nama"]) print(mahasiswa.get("prodi", "Belum diisi")) mahasiswa["prodi"] = "Teknik Elektro" for key, value in mahasiswa.items(): print(key, value)

Akses dengan tanda kurung siku akan memunculkan KeyError jika key tidak ada. Gunakan get() bila key bersifat opsional. Jangan menggunakan data sensitif nyata pada latihan publik.

Referensi Petani Kode: Dictionary ↗

12 / REUSABLE CODE

Fungsi

Fungsi membungkus tugas agar dapat dipanggil ulang. Parameter menerima masukan, return mengirim hasil kembali. Pisahkan perhitungan dari input/output agar fungsi lebih mudah diuji.

def hitung_rata_rata(data): """Mengembalikan rata-rata dari sequence angka.""" if not data: raise ValueError("Data tidak boleh kosong") return sum(data) / len(data) nilai = [80, 90, 85] rata = hitung_rata_rata(nilai) print(f"Rata-rata: {rata:.2f}")

Pelajari parameter positional, keyword, default, ruang lingkup variabel, docstring, dan nilai balik. Hindari mutable default seperti def f(items=[]); gunakan None sebagai default lalu buat objek baru di dalam fungsi.

Referensi Petani Kode: Fungsi ↗ · Dokumentasi fungsi ↗

13 / FUNCTIONAL TOOLS

Lambda

Lambda membuat fungsi anonim sederhana yang terdiri dari satu ekspresi. Gunakan saat fungsi singkat membantu memperjelas operasi, bukan untuk menyembunyikan logika kompleks.

kuadrat = lambda angka: angka ** 2 print(kuadrat(5)) data = [("Dina", 82), ("Bima", 91), ("Alya", 87)] urut = sorted(data, key=lambda item: item[1]) print(urut) angka = [1, 2, 3, 4, 5, 6] genap = list(filter(lambda n: n % 2 == 0, angka)) print(genap)

Untuk operasi sederhana, list comprehension atau fungsi bernama sering lebih mudah dibaca. Lambda hanya boleh berisi satu ekspresi, bukan blok statement multi-baris.

Referensi Petani Kode: Lambda ↗

14 / FUNCTION ARGUMENTS

*args dan **kwargs

*args menampung sejumlah argumen positional tambahan sebagai tuple, sedangkan **kwargs menampung argumen keyword tambahan sebagai dictionary. Tanda bintang juga dipakai untuk unpacking saat pemanggilan fungsi.

def ringkasan(judul, *args, **kwargs): print("Judul:", judul) print("Argumen tambahan:", args) print("Opsi:", kwargs) ringkasan( "Laporan", "draft", "review", penulis="Dina", versi=2 ) angka = [10, 20, 30] print(*angka) opsi = {"sep": " | ", "end": "\\n"} print("A", "B", **opsi)

Jangan memakai *args/**kwargs otomatis pada semua fungsi. Parameter eksplisit biasanya lebih mudah dibaca dan divalidasi. Gunakan bentuk variadik saat memang diperlukan fleksibilitas API.
