BATASAN & CATATAN TEKNIS

Runtime browser, bukan server Python penuh.

  • Python berjalan di WebAssembly melalui Pyodide. Paket standar tersedia; paket tambahan harus kompatibel dengan Pyodide.
  • Contoh NumPy memuat paket tambahan dan dapat menambah waktu unduh. Tidak semua paket PyPI dapat dipasang, terutama paket dengan ekstensi native yang belum dikompilasi untuk Pyodide.
  • Program yang membutuhkan akses OS, proses sistem, socket arbitrer, atau backend tidak setara dengan Python desktop.
  • Jangan jalankan kode tidak tepercaya dari sumber asing. Batas browser bukan jaminan bahwa kode berbahaya menjadi aman.
  • Jika runtime gagal dimuat, periksa koneksi internet, pemblokir konten, dan Console browser.
