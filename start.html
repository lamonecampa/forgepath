00 / THE BIG PICTURE

Bagaimana web bekerja?

Ketika membuka situs, browser bertindak sebagai client yang mengirim request ke server. Server memproses request, bisa membaca database, lalu mengirim response yang ditampilkan browser.

BROWSER (CLIENT) │ HTTP Request ▼ WEB SERVER (Apache / Nginx) │ ├── PHP menjalankan logika aplikasi │ │ │ └── MySQL menyimpan / mengambil data │ ▼ HTML + CSS + JavaScript │ HTTP Response ▼ BROWSER MENAMPILKAN HALAMAN

Peran tiap teknologi

  • HTML: struktur dan makna konten halaman.
  • CSS: tata letak dan tampilan visual.
  • JavaScript: interaksi yang berjalan di browser.
  • PHP: logika di sisi server.
  • MySQL: penyimpanan data relasional.
  • Laravel: framework PHP untuk menyusun aplikasi dengan pola dan alat yang konsisten.
Browser tidak menjalankan file PHP secara langsung. PHP perlu diproses oleh server atau PHP CLI. Membuka file .php langsung dari folder hanya menampilkan teks atau memicu unduhan, bukan menjalankan aplikasinya.
01 / STRUCTURE

HTML: susun halaman

HTML menggunakan elemen (tag) untuk memberi struktur. Elemen memiliki nama, atribut, dan konten. Mulai dengan dokumen paling sederhana.

<!doctype html> <html lang="id"> <head> <meta charset="utf-8"> <title>Halaman Pertama</title> </head> <body> <h1>Halo, dunia!</h1> <p>Ini halaman web pertama saya.</p> <a href="https://example.com">Contoh tautan</a> </body> </html>

Elemen yang sering dipakai

h1–h6 untuk heading, p untuk paragraf, a untuk tautan, img untuk gambar, ul/li untuk daftar, form/input untuk formulir, dan table untuk data tabular.

02 / PRESENTATION

CSS: atur tampilan

CSS memilih elemen lalu menerapkan aturan visual. Selector menentukan target, property menentukan aspek yang diubah, value menentukan nilainya.

body { font-family: Arial, sans-serif; background: #f4f6f2; color: #202820; margin: 0; } .card { max-width: 520px; padding: 24px; border: 1px solid #dce3dc; border-radius: 8px; }

Pahami box model: setiap elemen memiliki content, padding, border, dan margin. Biasakan memakai box-sizing: border-box untuk perhitungan ukuran yang lebih mudah.

03 / THINKING

Logika pemrograman

Sebelum bahasa pemrograman, pahami pola berpikir: input → proses → output. Program menjalankan instruksi secara berurutan, memakai percabangan untuk keputusan dan perulangan untuk pekerjaan berulang.

// Pseudocode menghitung kelulusan INPUT nilai IF nilai >= 70 THEN OUTPUT "Lulus" ELSE OUTPUT "Belum lulus" END IF

Konsep dasar

  • Variabel: tempat memberi nama pada nilai.
  • Operator: operasi aritmetika, perbandingan, dan logika.
  • Condition: if/else untuk memilih jalur.
  • Loop: for/while untuk pengulangan.
  • Function: kumpulan instruksi yang dapat digunakan ulang.
04 / BACKEND

PHP: mulai membangun logika server

PHP adalah bahasa pemrograman server-side. File PHP diproses oleh interpreter PHP, kemudian hasilnya (sering berupa HTML) dikirim ke browser.

<?php $nama = "Dina"; $nilai = 85; if ($nilai >= 70) { $status = "Lulus"; } else { $status = "Belum lulus"; } echo "Halo, " . htmlspecialchars($nama); echo " - " . $status; ?>

Siapkan lingkungan lokal

  1. Instal PHP melalui XAMPP, Laragon, atau instalasi PHP CLI.
  2. Buat folder proyek di document root (misalnya htdocs untuk XAMPP).
  3. Simpan kode sebagai index.php.
  4. Jalankan Apache dan buka http://localhost/nama-folder, atau jalankan php -S localhost:8000 dari folder proyek.
Latihan kode tersedia di PHP Playground untuk menjalankan PHP 8.4 langsung di browser. PHP Lab tetap tersedia untuk pemeriksaan pola kode dan latihan tambahan.
05 / DATABASE

MySQL: simpan data dengan terstruktur

Database relasional menyimpan data dalam tabel yang memiliki kolom dan baris. Primary key mengidentifikasi baris, sementara foreign key menghubungkan tabel.

CREATE DATABASE sekolah; USE sekolah; CREATE TABLE mahasiswa ( id INT AUTO_INCREMENT PRIMARY KEY, nama VARCHAR(100) NOT NULL, email VARCHAR(150) UNIQUE ); INSERT INTO mahasiswa (nama, email) VALUES ('Dina', 'dina@example.com'); SELECT id, nama, email FROM mahasiswa WHERE nama LIKE 'D%';

Empat operasi CRUD

  • INSERT: menambah record.
  • SELECT: membaca record.
  • UPDATE: mengubah record.
  • DELETE: menghapus record.
Gunakan SQL Lab untuk latihan query. Lab memakai SQLite di browser, bukan MySQL server. Konsep SQL dasarnya serupa, tetapi beberapa tipe data, fungsi, dan sintaks khusus berbeda.
06 / FRAMEWORK

Laravel: susun aplikasi dengan struktur

Laravel adalah framework PHP. Ia menyediakan routing, controller, middleware, validasi, migration, ORM Eloquent, templating Blade, dan banyak fasilitas lain agar aplikasi lebih terorganisasi.

Browser Request │ ▼ Route (routes/web.php) │ ▼ Controller │ ├── Model (Eloquent) ↔ Database │ ▼ View (Blade) │ ▼ HTML Response

Prasyarat sebelum mulai

  • Dasar PHP: variabel, array, function, OOP dasar, Composer.
  • Dasar SQL: SELECT, INSERT, UPDATE, DELETE, relasi tabel.
  • Terminal dasar dan pemahaman request/response web.
  • PHP, Composer, dan database yang sesuai dengan versi Laravel yang digunakan.

Contoh alur kerja Laravel

php artisan make:model Mahasiswa -m php artisan make:controller MahasiswaController php artisan migrate php artisan serve
Periksa versi Laravel dan persyaratan PHP di dokumentasi resmi sebelum instalasi. Contoh lama dari Laravel 5.x tidak selalu kompatibel dengan Laravel modern. Jangan mencampur tutorial lintas versi tanpa memeriksa perubahan API dan struktur proyek.
